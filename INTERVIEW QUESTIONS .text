1. What is SQL?

Answer:
SQL (Structured Query Language) is a language used to create, manage, retrieve, update, and delete data from relational databases.

2. Why is SQL used?

Answer:
SQL is used to manage data stored in databases. It helps users create tables, insert records, update information, delete data, and retrieve information efficiently.

3. Is SQL a programming language?

Answer:
SQL is a database query language. It is designed specifically for managing and querying relational databases, not for building complete software applications.

4. Name some databases that use SQL.

Answer:
