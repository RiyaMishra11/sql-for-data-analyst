1. What is SQL?

Answer:
SQL (Structured Query Language) is a language used to create, manage, retrieve, update, and delete data from relational databases.

2. Why is SQL used?

Answer:
SQL is used to manage data stored in databases. It helps users create tables, insert records, update information, delete data, and retrieve information efficiently.

3. Is SQL a programming language?

Answer:
SQL is a database query language. It is designed specifically for managing and querying relational databases, not for building complete software applications.

Q. What is a Database?
Answer

A database is an organized collection of related data stored electronically so that it can be easily accessed, managed, updated, and retrieved.

Without DBMS, managing millions of records would be very difficult.

Q. What is DBMS?
Answer

A Database Management System (DBMS) is software that allows users to create, manage, update, retrieve, and secure data stored in databases.

5. What is RDBMS?

(Relational Database Management System)

Definition

RDBMS stores data in the form of tables.

The tables are related to each other using keys.

What is RDBMS?
Answer

An RDBMS is a type of DBMS that stores data in tables and establishes relationships between those tables using keys such as Primary Key and Foreign Key.

Q. Difference between DBMS and RDBMS?
Answer

DBMS manages databases but may not support relationships between data. RDBMS stores data in related tables using Primary Keys and Foreign Keys, making it more secure and efficient.

6. What is a Table?
Definition

A table is a collection of related data arranged in rows and columns.

1. What is a table?

Answer:
A table is a collection of related data organized into rows and columns in a database.

2. What is the difference between a row and a column?

Answer:
A row represents one complete record, while a column represents one attribute (or field) of all records.

Example:
In an Employee table:

Row → 1 | Riya | 45000 | HR
Column → Salary contains all employees' salary values.

3. What is a field?

Answer:
A field is a single data value stored in a cell of a table. For example, 45000 in the Salary column is a field.

Q. What is the CREATE command?

Answer:
The CREATE command is a DDL command used to create new database objects such as databases, tables, views, and indexes.

Q. Why do we use ALTER?

Answer:
ALTER is used to modify the structure of an existing table without deleting the table or its data.

Q. What does DROP delete?

Answer:
DROP deletes both the table structure and all data stored in the table.

Q. What is TRUNCATE?

Answer:
TRUNCATE removes all rows from a table but keeps the table structure for future use.

Q. What is INSERT used for?

Answer:
The INSERT command is used to add one or more new rows into a table.

Interview Question

Q. What happens if WHERE is omitted in UPDATE?

Answer:
All rows in the table will be updated, which may lead to accidental data modification.

Q. What is the purpose of SELECT?

Answer:
SELECT is used to retrieve data from one or more tables based on specified conditions.

Q. What is the difference between GRANT and REVOKE?

Answer:
GRANT provides permissions to users, while REVOKE removes previously granted permissions.
